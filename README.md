# Krysko Macmonitor

## How do I install these formulae?

`brew install krysko/macmonitor/macmonitor`

Or `brew tap krysko/macmonitor` and then `brew install macmonitor`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "krysko/macmonitor"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
